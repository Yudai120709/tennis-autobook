# 都営テニスコート 空き監視・通知（GitHub Actions 版）

GitHub のサーバー（完全無料・Public）で自動稼働しているので、パソコンやスマホを閉じていて大丈夫です。

---

## 動き

| 動き | タイミング | 内容 |
|---|---|---|
| **① ふだんの空き監視** | **毎日 6:00 〜 24:59 の間、5分おき**<br>（※深夜1:00〜5:59は停止） | 西船橋から行きやすい全10公園の空き枠を5分おきに自動チェック。<br>・**空きが出た瞬間**：即座に「【空き発見】」メールを通知。<br>・**空きがない時**：約1時間に1回「【定期報告】（現在空きなし）」メールを送信。 |
| **② 22日の一斉解放** | **毎月21日 23:30〜待機 ➔ 22日 00:00:01 に開始** | 0時ジャストに最優先4公園（木場・日比谷・芝・猿江）を**4並列で同時スキャン**。<br>見つかった空き枠一覧とスポレク予約リンクを最速でメール通知。 |

---

## 監視条件（config.json）

* **対象時間帯**
  * **平日**：19:00 以降に始まる枠
  * **土日・祝日**：すべての時間帯（朝7:00〜夜21:00）
* **対象公園（西船橋から行きやすい公園）**
  * **平日**：木場公園、日比谷公園、芝公園
  * **土日祝**：木場公園、猿江恩賜公園、亀戸中央公園、大島小松川公園、篠崎公園Ａ、有明テニスＣ（人工芝）、有明テニスＡ（屋外ハード）、東綾瀬公園、東白鬚公園、汐入公園
* **対象期間**：今日から6日後以降 〜 60日後まで
* **通知方法**：Gmail 経由で iPhone（VIP通知）宛に即時メール送信

---

## 手動での実行方法（テスト確認）

1. GitHub の **「Actions」** タブを開く
2. 左メニューの **「テニスコート空き監視・通知」** をクリック
3. 右上の **「Run workflow」** ➔ **「check」** を選んで緑色の **「Run workflow」** を押す
   （※約2〜3分で完了し、最新の空き状況を確認できます）
